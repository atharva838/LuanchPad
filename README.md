LaunchPad is a student career and opportunity management platform. It helps students discover internships, hackathons, scholarships, workshops and competitions, then track their applications in one place. 
| Feature | What it does |
|---|---|
| Dashboard | Displays application statistics and progress |
| Discover opportunities | Browse and search opportunities |
| Advanced filters | Filter by opportunity type and work mode |
| Application tracker | Track Interested, Applied, Assessment, Interview, Offer and Rejected statuses |
| Saved opportunities | Bookmark opportunities for later |
| Add opportunity | Create custom opportunity listings |
| Follow-up notes | Store notes and application dates |
| XML export | Download your data as a structured XML backup |
| XML import | Restore and merge data from an XML backup |
| AJAX / Fetch API | Load opportunity data asynchronously |
| Local storage | Preserve your changes after refreshing |
| Dark mode | Switch between light and dark themes |
| Responsive UI | Adapt to desktop, tablet and mobile screens |

index.html — dashboard, navigation, forms, tables and dialogs.
styles.css — complete styling, responsive layouts and dark mode.
app.js — application logic, event handling, Fetch API, XML processing and storage.
opportunities.json — sample opportunity dataset.
README.md — setup instructions, features and testing checklist.

One limitation to understand: this version is frontend-only. Its data is stored in the current browser, not a shared database. The opportunities are illustrative sample listings, not verified live openings.
